# 快做啊! - doro 表情包生成器（本地版）

参考 [kuaizuoa.alitenna.com](https://kuaizuoa.alitenna.com/) 的交互与视觉版式制作的本地版本，
底图换成了 doro 动画。**完全离线运行，不依赖任何网络资源。**

## 运行方式

**直接双击 `index.html`** 即可在浏览器（Chrome / Edge）中使用，无需安装任何东西。

如果偏好以 HTTP 方式运行（可选），在 `02-system` 目录下执行：

```bash
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080/
```

## 功能（与参考站一致）

| 功能 | 说明 |
|------|------|
| 头像 | 点击或拖拽上传 → 圆形裁剪（Cropper.js），自带淡青色描边；支持"重新裁剪 / 更换头像" |
| 头像位置 | 折叠面板内可调 左右 / 上下 / 大小，也可以**直接在预览图上拖动头像** |
| 头像动效 | 与参考站相同的"Y 轴旋转 + 弹跳"效果，每 GIF 循环一次，可关闭 |
| 文字 | 任意文字，默认"快做啊！" |
| 字号 | 10–100 |
| 微调位置 | 文字的 左右 / 上下 |
| 速度 | 0.5–3.0 倍速，**默认 1.0 = 原始 GIF 原生节奏**；导出时自动跳帧保证最小帧延迟，预览实时生效 |
| 导出 | 仅 **导出 GIF**（512×512，循环播放），按参考站同样方式下载 |

另有：深色模式 / 中英文切换（右上角，偏好自动保存）。

## 目录结构

```
02-system/
├── index.html            页面入口
├── css/style.css         样式（布局沿用参考站版式，含深色模式）
├── js/app.js             主逻辑：状态 / 逐帧合成 / 旋转弹跳 / 预览 / 裁剪 / 导出 / 双语
├── js/gif-parser.js      GIF 解帧（优先 WebCodecs ImageDecoder，退化 img 轮询）
├── js/gif-encoder.js     GIF89a 编码器（全局调色板 + 抖动 + 帧间透明差分 + LZW）
├── js/doro-data.js       doro 清洁底图（base64 内嵌，自动生成，勿手改）└── vendor/cropper/       Cropper.js 1.6.2（本地化，离线可用）
```

> 所有脚本均为经典脚本（无 ES Module、无 fetch），因此 `file://` 双击打开时
> canvas 不会被跨域污染，导出功能可正常工作。

## 更换 / 重新生成底图

底图为 doro 动画的清洁版（已去除原素材中烘焙的他人文字与头像贴片，
保留完整 14 帧动作循环，含"放大重击"段），以 base64 形式内嵌在 `js/doro-data.js`。

想换成别的 GIF 作为底图时：

```bash
# 1. 准备一张干净的循环 GIF（建议方形、单循环动作、帧延迟不小于 2cs）
# 2. 重新生成内嵌数据（Git Bash）：
base64 -w0 你的底图.gif > tmp.b64
# 3. 用新 base64 替换 02-system/js/doro-data.js 中引号内的内容即可
```

## 实现说明

- 解帧 / 编码算法移植自参考站（其实现适配自 ring-tool），行为保持一致：
  导出时按速度计算目标总时长，帧延迟最小 2cs（浏览器安全下限），高倍速自动跳帧。
- 头像动效参数（转速 1.2 圈/周期、最小压扁 0.2、弹跳幅度 30%、峰值位于周期 15/23 处）
  与参考站默认值相同。
